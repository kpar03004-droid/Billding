# 빌띵 (Billding)

**띵타이쿤 골드 수입·지출 자동 가계부 모드**

하루에 얼마 벌고 얼마 썼는지, 어떤 활동에서 나왔는지를
화면에 이미 보이는 정보(채팅·보유 골드·열어 본 창)만 읽어 자동으로 정리해 줍니다.

마인크래프트 **1.21.4** · **Fabric / NeoForge** · 클라이언트 전용

</div>

---

## ⬇️ 다운로드

### **[▶ 최신 버전 받기](../../releases/latest)**

위 링크에서 사용하는 로더에 맞는 파일 **하나만** 받으세요.

| 로더 | 파일 |
|---|---|
| **Fabric** | `billding-fabric-*.jar` |
| **NeoForge** | `billding-neoforge-*.jar` |

> Fabric 사용 시 **Fabric API** 와 **YetAnotherConfigLib(YACL)** 도 함께 필요합니다.

---

## 📥 설치

1. 기존 빌띵 파일이 있으면 mods 폴더에서 **삭제**하세요. (안 지우면 충돌)
2. 받은 파일을 mods 폴더에 넣으세요. (로더에 맞는 것 하나만)
3. 게임을 **완전히 종료했다가 다시 실행**하세요.

기존 기록·설정은 그대로 유지됩니다.

---

## 🕹️ 기본 사용법

- 채팅에 **`/빌띵`** → 정산창 (오늘 / 주간 / 내역 / 금고 / 관리 / 설정)
- 화면 한쪽에 오늘 수입·지출 **HUD** 표시 → 위치·크기 편집은 **`/빌띵 위치`**
- 엑셀 내보내기: **`/빌띵 내보내기`** (거래내역·일별·주별·카테고리 4시트)

> 한글이 기본이고 기존 `/dtstat` 계열도 그대로 됩니다.
> 자세한 명령어와 사용법은 릴리스에 첨부된 **설명서**를 봐주세요.

## 🔒 안전성 (서버 규칙 준수)

빌띵은 **이미 화면에 보이는 정보만** 읽어 다시 정리해 보여줍니다.

- 서버로 **아무것도 보내지 않습니다.**
- 자동 조작·매크로 기능이 없습니다.
- 화면에 안 보이는 정보를 캐내지 않습니다.

> "거울이지 망원경이 아니다." — 보이는 걸 정리할 뿐, 안 보이는 걸 보이게 하지 않습니다.
